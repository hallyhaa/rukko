# Rukko

> **This project has moved to [GitLab](https://gitlab.com/hallyhaa/rukko).** This GitHub repository is archived and will not receive updates.

A Rust library for communicating with [Apache Pekko](https://pekko.apache.org) JVM actors over the Artery TCP protocol. Allows Rust applications to send messages to and receive replies from Pekko actors. Published on [crates.io](https://crates.io/crates/rukko), documented on [docs.rs](https://docs.rs/rukko).
